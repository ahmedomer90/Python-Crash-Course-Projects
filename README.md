# Python Crash Course Projects

This repository contains projects I completed while working through *Python Crash Course, 3rd Edition* by Eric Matthes.

The repository contains the three major projects from the book: the Alien Invasion game, data visualization with Python, and the development of a Django web application.

## Project 1: Alien Invasion

The `project_1_alien_invasion` directory contains a 2D space-invasion game developed with Python and Pygame.

Features include:

- Player-controlled spaceship
- Alien fleets
- Bullet firing and collision detection
- Scoring and high-score tracking
- Multiple difficulty levels
- Play button and game-state management
- Image-based game sprites

## Project 2: Data Visualization

The `project_2_data_visualization` directory contains Python programs exploring data generation, visualization, external datasets, and web APIs.

Topics covered include:

- Data visualization with Matplotlib and Plotly
- Random walks
- Simulating dice rolls
- Working with CSV weather data
- Visualizing temperature data
- Processing earthquake data in GeoJSON format
- Mapping earthquake activity
- Working with web APIs
- Exploring GitHub repository data
- Exploring Hacker News data

## Project 3: Learning Log Web Application

The `project_3_learning_log` directory contains a Django web application developed while working through the web applications project.

The Learning Log application allows users to create an account and maintain notes about topics they are learning.

Features include:

- Django models, views, URLs, and templates
- User registration and authentication
- Topic creation
- Adding entries to individual topics
- Editing existing entries
- Associating topics with individual users
- Restricting access to authenticated users
- Bootstrap-based page styling
- Custom error pages
- Django database migrations
